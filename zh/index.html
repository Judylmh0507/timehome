您购买的是什么

约 320 件 美式家具，2009 至 2012 年间生产，此后一直存放于保税仓。库存 从未开封、从未陈列、从未使用，我们按 原出口包装发货，与出厂时完全一致。

我们是专门清仓这批库存的经销商。我们不生产家具，不是原工厂也不是 OEM 车间 — 我们只是持有这批长期库存并以清仓价格出售。请勿将其理解为"工厂直销"或 OEM 货源；我们的价格反映的是这批库存的年代和清仓性质。

材质 — 请注意

材质 因件而异。多数产品采用 实木框架 + 优质实木皮 + 部分人造板辅材。它们 不是 100% 纯实木。每件产品的确切材质构成会在产品页面列出。我们如实描述材质，而非将所有产品标为"全实木"。

可能的岁月 / 存放痕迹

由于库存长期存放多年，根据我们过往销售经验，产品 可能 出现轻微的岁月痕迹。这些痕迹最多只影响表面，大多数情况下 不影响 木材或结构。常见痕迹：

  • 包装陈旧 / 积灰 — 原包装可能看起来老旧，有灰尘或存放痕迹。
  • 霉点 / 受潮痕迹 — 包装表面因长期存放可能出现轻微水渍；木材本身通常不受影响。
  • 潜在磕碰 — 隐藏的磕碰或划痕，仅在开箱后才能发现。
